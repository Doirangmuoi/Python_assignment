# BÀI TẬP LỚN PYTHON: NEWS CRAWLER
## Ứng dụng Console Thu thập và Quản lý Tin tức Đa nguồn

### 🚀 Cách chạy nhanh:
1. Kích hoạt Virtual Environment (nếu có):
   ```powershell
   .\python_threading_basic\.venv\Scripts\activate
   ```
2. Chạy ứng dụng từ thư mục gốc:
   ```bash
   python run.py
   ```
   Hoặc di chuyển vào thư mục dự án:
   ```bash
   cd python_threading_basic
   python main.py
   ```

3. Chạy kiểm thử tự động (Unit Test):
   ```bash
   python -m unittest python_threading_basic/tests/test_news_crawler.py
   ```
